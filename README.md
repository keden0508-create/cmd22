# Command Helper (Fabric 26.3 클라이언트 모드)
GitHub 웹사이트에서 이 폴더 내용을 업로드 → Actions 탭에서 build 실행 → cmdhelper-jar 다운로드.

## 재미용
/magum 마검, /thunderall 모든 플레이어 번개, /thunderme, /thundermobs, /storm,
/god /speed /jump /nv /heal /feed /clearfx, /rocket, /boom, /boomall, /rtp,
/apple, /totem, /kit(네더라이트 세트), /bye(전원 번개+TNT), /head 닉네임, /cmdhelp

## 추가 기능
/cb x y z · /cbnear (커맨드블록 열기), /im /imh /cmd (item_model·custom_model_data give),
/gimmick (맵 제작 기믹 사전), /exec (execute 사전), /nether /chunk /copyxyz /stack /ticks /dice /coin /shrug /tableflip /mark /marks /tpmark /unmark
